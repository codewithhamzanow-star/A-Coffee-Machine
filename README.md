# ☕ Coffee Machine

My first Python project, built to practice programming logic and
fundamental Python concepts.

## What I Practiced

- Dictionaries and nested dictionaries
- Functions and parameters
- `for` and `while` loops
- Input validation
- `try` / `except`
- Conditional logic
- Resource management
- Breaking a program into separate functions

## How It Works

The user can:

- Order an espresso, latte, or cappuccino
- Check the machine's resources using `report`
- Insert coins and receive change
- Receive a message when resources are insufficient
- Turn the machine off using `off`

## What I Learned

This project helped me understand how different functions can work
together to manage a program and how dictionaries can be used to
represent structured data.
